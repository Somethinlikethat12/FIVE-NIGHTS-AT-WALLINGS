Enter the pizzeria

This is the multiplayer-world prototype for the original night-shift game. Explore the building with other guards, chat, take jobs, and launch shared survival shifts. A free Supabase project provides the realtime connection; no local computer setup is required. This first milestone is a shared lobby and cooperative shift simulation, not yet a fully persistent MMO.

Connection setup is a one-time step per browser. Use only the project's public anon key—never a service-role or secret key. This build uses Supabase Realtime presence/broadcast for live sessions. The included SQL schema is groundwork for future account profiles and saved progression; those features are not wired up yet.
